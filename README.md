Cafe Management System
Overview:
This project is a console-based Cafe Management System built using Java and Object-Oriented Programming (OOP) concepts. 
It helps manage cafe orders and menu items through a simple interactive menu.
Features Implemented:
-Add and manage snack orders
-Automatically calculate total prices
-Remove orders by item name
-Validate user input using Scanner
-Interactive console menu system
OOP Concepts Used:
-Classes and Objects
-Inheritance
-Encapsulation
-Constructors
-Method Overriding
